Автосервис (Вариант 42)
Описание
Лабораторная работа 1. Реализация предметной области "Автосервис", генерация данных с помощью Bogus и LINQ-запросы, покрытые xUnit v3 тестами.

	Стек
1).NET 10
2)xUnit v3
3)Bogus (Генерация датасета от 10+ экземпляров)
4)FluentAssertions
5)GitHub Actions (CI/CD)
	Структура предметной области
1)Автомобиль (Гос. номер, Марка, Модель, Год)
2)Вид работ (Название, Категория, Стоимость, Продолжительность)
3)Клиент (ФИО, Телефон, Список авто)
4)Механик (Номер паспорта, ФИО, Специализация(Enum), Стаж)
5)Заказ (Авто, Клиент, Механик, Список работ, Даты)
	LINQ Запросы (Юнит-тесты)
1)Механики по виду работ.
2)Клиенты по механику (упорядочены по ФИО).
3)Количество повторных обращений за последний месяц.
4)Суммарная стоимость работ заказа.
5)Топ 5 наиболее частых видов работ.
	Запуск тестов локально
dotnet test
